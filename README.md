# VoIPDeck downloads

VoIPDeck is a Windows tool for bulk work on NetSapiens phone platforms. More at [voipdeck.io](https://voipdeck.io).

This repository only holds the program for download. The source code isn't here.

## Install

1. Download `VoIPDeck.exe` from the newest release under [Releases](../../releases).
2. Run it. It installs itself for your Windows user (no admin needed), adds a desktop and Start menu shortcut, and opens.
3. Add the license key you were sent.

## Updates

VoIPDeck checks voipdeck.io for a new build every 2 hours. That check is the only thing it ever sends out, and it sends nothing about you. Every update is signed and checked before it runs, and a new build that fails to start is undone by itself. You can turn the checks off on the sign-in screen.

A new download from here is only needed now and then, when VoIPDeck says so.
